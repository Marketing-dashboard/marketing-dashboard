⚙️ One-time Setup Required

This sheet is private. You need to deploy a Google Apps Script Web App once so the dashboard can securely read the data. It takes about 2 minutes.

  1. Open your Google Sheet → click Extensions → Apps Script
  2. Paste the contents of ims_data_server.gs (in the same folder as this file)
  3. Click Deploy → New deployment → Type: Web app
  4. Set Execute as: Me  |  Who has access: Anyone
  5. Click Deploy → copy the Web app URL
  6. Paste the URL below and click Connect
