How it is worked out

  • Completion = Generation ÷ Requirement for the same days. Gap = Generation − Requirement (negative means short).
  • The last day with NCBD generation above zero is the last reported day. Requirement for later days is left out, so the current month compares like with like. The sheet's own month column includes those days, so its current-month % reads lower.
  • Month figures are summed from the sheet's daily columns. Where the sheet's month-total column disagrees with its own days, this page follows the days.
  • NCBD overall includes some leads outside the NCD Meta + Google split. The NBD Facebook block in the sheet is empty, so it isn't shown.
  • Source: Google Sheet "NCBD Requirement VS Generation", tab "Req VS Gen".
